                           QUICK START (5 MIN)
================================================================================

STEP 1: Create Database
   Windows PowerShell:
   $ .\setup-windows.ps1

   Or manual:
   $ psql -U postgres -c "CREATE DATABASE document_ai;"

STEP 2: Start Backend (Terminal 1)
   $ cd backend
   $ mvn spring-boot:run

   Wait for: "Started DocumentAiServiceApplication"

STEP 3: Start Frontend (Terminal 2)
   $ npm install
   $ npm run dev

   Wait for: "Local: http://localhost:5173"

STEP 4: Test
   1. Open http://localhost:5173
   2. Drag a .txt or .json file onto the upload area
   3. Click "Upload Document"
   4. See data imported to PostgreSQL! ✨

================================================================================
                           CONFIGURATION
================================================================================

Default Settings (in .env):
   DB_URL=jdbc:postgresql://localhost:5432/document_ai
   DB_USERNAME=postgres
   DB_PASSWORD=postgres
   DDL_AUTO=create-drop (development)
   SERVER_PORT=8080
   FRONTEND_PORT=5173

Change these if your PostgreSQL is different:
   1. Edit .env file
   2. Restart backend
   3. Restart frontend

For Production:
   1. Change DDL_AUTO=update (preserves data)
   2. Use strong PostgreSQL password
   3. Update DB_URL for production server
   4. Setup SSL/HTTPS
   5. Follow DEPLOY.md guide

================================================================================
                          TROUBLESHOOTING
================================================================================

Problem: PostgreSQL connection refused
Solution:
   1. Verify PostgreSQL is running
   2. Check .env has correct credentials
   3. Test: psql -U postgres

Problem: Database doesn't exist
Solution:
   1. Run: psql -U postgres -c "CREATE DATABASE document_ai;"
   2. Or run: .\setup-windows.ps1

Problem: Port already in use (8080)
Solution:
   1. Change in: backend/src/main/resources/application.yml
   2. Set: server.port: 8081

Problem: Maven build fails
Solution:
   1. Run: mvn clean install -X
   2. Or: mvn dependency:resolve

Problem: Frontend won't load
Solution:
   1. Run: npm install
   2. Then: npm run dev

See SETUP.md or VERIFY_SETUP.md for more troubleshooting.
